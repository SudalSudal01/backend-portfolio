# 김명현 | 백엔드 개발자 포트폴리오

공개 웹: https://SudalSudal01.github.io/backend-portfolio/

제때약 → 여행픽 → 5ASIS 순으로 담당 기능과 설계·검증 경험을 소개합니다.
팀 프로젝트의 개인 기여와 전체 성과를 구분하고 개인 포크와 팀 원본을 함께 연결합니다.

- `index.html`, `style.css`, `app.js`, `data.json`: 정적 웹
- `assets/kim-myeonghyeon-portfolio.pdf`: 지원용 PDF
- `assets/profile.png`: 본인이 제공한 프로필 사진
- `main` 루트의 파일을 GitHub Pages로 배포합니다. `.nojekyll`은 정적 파일을 그대로 제공합니다.

서비스 API·DB·환경변수는 포함하지 않습니다. 포트폴리오는 사용자에게 공개를 허용받은 프로필과 프로젝트 설명으로 구성합니다.
